# KJ Tech Web – Assistência Técnica Digital

Projeto extensionista "Web para Todos" – Programação para Internet – Universidade Universo Recife (2026.2).
Equipe: Nicolas Minduca, Kaynan, Thiago Felipe e Luan Rodrigues. Professor: Carlos Silva.

Beneficiário: Kj Tech – Ipsep.

## Como abrir

Abra o arquivo `index.html` no navegador. Não precisa instalar nada.

## Estrutura

```
index.html       Página inicial
servicos.html    Serviços
sobre.html       Sobre a Kj Tech
contato.html     Contato, localização e formulário
orcamento.html   Formulário de orçamento
css/style.css    Estilos (cores no início do arquivo)
js/script.js     Menu responsivo e validação dos formulários
img/             Imagens autorizadas (vazia por enquanto)
```

## Pendências antes de publicar

Procure por `[PREENCHER]` e `[CONFIRMAR` nos arquivos HTML e substitua pelas informações confirmadas pela Kj Tech
(telefone/WhatsApp, endereço, horário, serviços, garantia). Remova também os avisos amarelos da equipe.

## Formulários

Nesta versão os formulários **só validam os campos** e mostram uma mensagem de sucesso; nenhum dado é enviado
nem armazenado. Para receber solicitações reais, é preciso definir com o beneficiário um canal oficial
(por exemplo, WhatsApp ou e-mail) ou um serviço de formulários.

## Guia rápido de atualização

- **Alterar textos:** abra o `.html` da página, localize o texto, edite e salve.
- **Substituir imagens:** coloque o arquivo na pasta `img/`, use `<img src="img/arquivo.jpg" alt="descrição">` e sempre escreva o texto alternativo.
- **Atualizar serviços:** copie um bloco `<article class="card">` em `servicos.html` e edite título e descrição.
- **Atualizar contato:** edite os cartões em `contato.html` (somente dados confirmados).
- **Cores:** altere as variáveis no início de `css/style.css`.
- **Senhas e dados pessoais:** nunca coloque senhas nem dados de clientes no código.
